# Skyrim SE 1.7.99 / 1.7.104: what the renderer needed

1.7 support is experimental (see the end of this file). It needs a CommonLib with the 1.7 changes (an MIT fork of
CommonLibVR-ng 4.10.0; not part of this repo), selected with `-DSKYRIMRENDERER_COMMONLIB_DIR=<checkout>` in a build
folder of its own. Every 1.7 value here comes from the two game executables (1.6.1170, decrypted from a running
process, and 1.7.104), the Address Library files and that CommonLib. No GPL CommonLib was read.

Tools: comparison scripts over the two executables (functions by Address Library ID, vtables, RTTI base lists,
fields read through singletons), including `ripfields.py` for fields of a static object read rip-relative,
compared instruction by instruction in every function with the same ID and shape.

New code that uses a game address or offset should get its 1.7 value the same way (or go through a CommonLib
accessor that has one) and note it below.

## Changed for 1.7

| What | 1.6.1170 | 1.7.104 | Source | Renderer change |
|---|---|---|---|---|
| `PlayerCharacter` tint masks (`tintMasks`, `overlayTintMasks`) | 0xB18, 0xB30 | 0xB20, 0xB38 | `PlayerCharacter::GetTintMask` (40698) reads 0xB18 / 0xB28 (count) in 1.6 and 0xB20 / 0xB30 in 1.7; the new `BSTEventSink<BSSystemEvent>` base at 0x2D8 (RTTI) | The two hand-written offsets in `ActorPreview.cpp` now go through `GetPlayerRuntimeData()`, which the fork versions for 1.7 (and which gives SE / AE exactly as before) |

The DLL is not an SKSE plugin (consumers load it), so SKSE 2.3's `kVersionIndependentEx_AddressLibraryV5` does
not apply to it; its consumers declare it.

## Status: experimental

1.7 support is experimental. Besides the checks above, one in-game smoke test ran on 1.7.104: a test
plugin loaded the DLL like a consumer and rendered the player (full preview, dressed without headgear, head at rest
with all five shapes resting on their live FaceGen rest) and Lydia from her base form (default outfit, FaceGen
head), then installed the Present hook. Every step passed, the images were correct and the renderer logged no
warnings or errors. Nothing beyond that was tested: no real consumer (NTJH, Dress Code) ran on 1.7, and live
mirrors, animation, the Community Shaders path and long sessions are unverified.
